Privacy Policy

Effective Date: August 27, 2026 • Last Updated: August 27, 2026
Core Commitment: PDF Toolkit was engineered from the ground up on a fundamental principle: your documents and files never leave your computer or phone. All processing happens entirely within your web browser's local sandbox memory.

1. Introduction

Welcome to PDF Toolkit ("we," "our," or "us"). We operate pdftoolkit.com. This Privacy Policy explains in complete detail how our service works, what technical information we may collect, what data we never collect, and how third-party advertising partners like Google AdSense interact with your browser.

2. Client-Side Processing Architecture: Zero File Uploads

Unlike traditional online PDF converters and utilities that upload your sensitive documents to remote cloud servers for manipulation, PDF Toolkit operates 100% on the client side.

  • No Server Transmission: When you select or drag and drop a document into any of our tools (Merge, Split, Compress, JPG to PDF, or PDF to JPG), the file is read solely into your browser's local RAM memory via standard HTML5 File APIs.
  • Local CPU Execution: All document modifications, PDF assembly, image decoding, and compression algorithms run on your device using WebAssembly and client-side JavaScript libraries (such as pdf-lib and Canvas).
  • Zero File Storage: We maintain zero backend document storage databases, zero caching buckets, and zero file ingestion queues. At no moment during or after processing does anyone at PDF Toolkit or any third party have access to your documents.
  • Memory Release: Once you close the tab or refresh the page, your browser automatically flushes all loaded documents from temporary memory.

3. Data We Do Not Collect

Because of our privacy-by-design architecture, we do NOT collect, read, inspect, or retain:

  • The contents, text, images, or metadata inside your PDF or image files.
  • The file names, extensions, or directory structures of your files.
  • User account credentials (no registration or sign-in is required to use our suite).
  • Financial, legal, or personal information contained in processed documents.

4. Technical Information & Web Analytics

When you visit our website, our web server hosting provider (such as Vercel or Cloudflare) may automatically record standard technical log entries that web browsers commonly transmit. This data includes:

  • Internet Protocol (IP) address.
  • Browser type, language, and operating system version.
  • Referring URL and requested pages.
  • Date and timestamp of visits.

These access logs are used strictly to maintain website security, prevent Distributed Denial of Service (DDoS) attacks, ensure server stability, and diagnose technical errors. This data is never correlated with any user file contents.
